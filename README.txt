GOIASRP LAUNCHER - PRIMEIRA VERSAO CATALOGO DE CARROS

Esta versao adapta a base do launcher para um catalogo de carros brasileiros.

Recursos:
- Busca por marca/modelo
- Filtro por fabricante
- Cards de veiculos
- Ano, motor e preco de referencia
- Tela de detalhes
- Interface azul/preta
- Splash screen
- Sem dependencias externas

Para usar no GitHub:
1. Extraia este ZIP.
2. Envie o conteudo para a raiz do repositorio GoiasRP-Launcher.
3. O workflow .github/workflows/build-apk.yml gera o APK de debug.
